# Flightline

A calm, Apple-inspired live flight tracker powered by Aviationstack.

## Stack
- Next.js
- React
- Leaflet / React Leaflet
- Aviationstack

## Setup
Create `.env.local` with `AVIATIONSTACK_ACCESS_KEY` and run `npm install` then `npm run dev`.

The Aviationstack key stays server-side in `/api/flight-status`.
